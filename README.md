# Vietnamese Medical RAG QA System

This project builds a Vietnamese Medical Question Answering system using Retrieval-Augmented Generation.

## Goals

- Build a Vietnamese medical document corpus
- Create text embeddings
- Store vectors using FAISS
- Retrieve relevant medical passages for user questions
- Generate grounded answers with source citations
- Evaluate retrieval and answer quality
